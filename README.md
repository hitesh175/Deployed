# Portfolio Website Archive

A static portfolio implementation with supporting styles, scripts, images, and certificate graphics.

## Entry points

- [Portfolio homepage](Portfolio%20Parallax/index.html)
- [Alternative page](Portfolio%20Parallax/try.html)

## Preview locally

From the repository root:

```bash
python -m http.server 8000
```

Open `http://localhost:8000/Portfolio%20Parallax/index.html`.

Keep the full directory structure intact so relative images, styles, and scripts resolve. External resources used by the page require network access.

## Repository context

This repository contains a static portfolio version. The separate [Hitesh_Portfolio](https://github.com/hitesh175/Hitesh_Portfolio) repository contains a React/TypeScript implementation.

The repository name does not establish the status of a live deployment. Review the page's contact information, links, and third-party asset attribution before publishing a new version.
